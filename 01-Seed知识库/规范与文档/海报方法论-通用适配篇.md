# 贴纸海报方法论 · 通用适配篇

> 前提：`订票机器人海报设计方法论.md` 是"病例"，本文是"医理"。
> 核心结论：那套海报 = **叙事层 + 结构层 + 风格层**。前两层完全通用，第三层（贴纸风/登机牌/钉钉蓝）只是皮，换业务时整张换掉。

---

## 一、三层解耦：迁移时动哪层、不动哪层

| 层 | 内容 | 迁移时 |
|---|---|---|
| 叙事层（通用） | Before→After 对比、单张单卖点、说人话不说参数、系列叙事弧 | **原样保留** |
| 结构层（通用） | 五段式竖屏构图、双条斜叠标题、三徽章、金句横幅+CTA、六个固定槽位 | **原样保留** |
| 风格层（可换） | 视觉母题（登机牌）、贴纸拼贴质感、吉祥物、配色三角色的具体色值 | **按业务整体换肤** |

想通这一点，"订票机器人方案"就变成了一个填空模板：**换母题、换痛点、换品牌色、换吉祥物，骨架不动。**

## 二、五步适配法（任何业务照此走）

### 第 1 步：找到你的"登机牌"（定母题）
订票机器人的灵魂是登机牌——业务里**高频出现的实体物件**。每个业务都有自己的那个物件：

| 业务 | 母题候选 | 徽章变体 |
|---|---|---|
| 报销 | 发票、收据、贴票单 | 报销章、回执贴纸 |
| 薪酬 | 工资条、算盘、计算器纸带 | 薪级邮戳 |
| 招聘 | 简历、offer 信封、工牌 | 录取检票章 |
| 考勤 | 打卡工卡、钟表 | 全勤邮票 |
| 审批 | 盖章单据、卷宗、签批单 | 审批通过章 |
| 知识库 | 索引卡、书签、图书馆标签 | 分类藏书票 |
| 数据报表 | 表格纸、图钉图表 | 数据校验章 |
| 培训 | 结业证书、课程票 | 学分邮票 |

**母题四条检验标准**：①外行一眼看懂业务；②能承载标题文字（做成票笺/卡片）；③能拆出徽章变体（邮戳/标签/贴纸）；④自带"流程感/票据感"。
找不到实物母题的业务，用"场景"当母题（如办公桌、会议室），但优先找实物。

### 第 2 步：列旧流程痛点清单（定文案素材）
把用户现在的完整旧流程逐步写下来，每一步 = 未来的一集。订票系列的编号就是这么来的：01 开网页（5 个网页下线）→ 02 比价 → 03 核对 → 04 填表 → 05 筛选 → 06 出行。
**痛点清单比功能清单重要**——每集标题的前句从痛点里来，不从功能里来。

### 第 3 步：痛点翻译成人话标题（填 ② 槽）
公式：**前句 = 痛点的口语吐槽（米白底），后句 = 产品替代动作（焦点色底）**。

| 公式 | 原例 | 通用化 |
|---|---|---|
| 数字对比 | 5 个网页，下线。1 句话，上线。 | N 个麻烦，清零。1 个动作，办完。 |
| 熟语挪用 | 别玩"找不同"/ 不必靠眼神 | 借大众熟语吐槽痛点 |
| 对仗拟人 | 你说人话，它听得懂。 | 你说 X，它懂 Y。 |
| 让步转折 | 航班很多，你不用全看。 | X 很多，你不用 Y。 |

铁律：短句+逗号断句+句号入画；只说体感词（费劲/来回/逐条/加班），不说参数词（引擎/模型/系统）。

### 第 4 步：画 Before→After（填 ③④ 槽）
- 主视觉永远是**左边乱、右边净**：旧方式画成皱纸、乱飞的标签、问号涂鸦、水彩乱涡；新方式画成整齐卡片、绿色对勾、星光。中间用箭头/产品化身（气泡/logo 漏斗）连接。
- 三徽章填法：动词开头，各 ≤7 字，三色错开。动词库：**自动 X / 一句话 X / 少一点 X / 随时 X / 免 X / X 一眼可见**。

### 第 5 步：金句 + 配色换肤（填 ⑤ 槽）
**金句公式库**（"A 归 A、B 归 B"式的立场句，通用模板直接套）：
- 分工式：A 交给机器人，B 留给你。
- 让步式：X 可以很 Y，Z 应该很 W。
- 取舍式：把 A 留在 B，把 C 带上路/还给自己。
- 立场式：该 X 听懂人，不是让人迁就 X。
- 承诺式：在 X 之前，少留一个 Y。

**配色三角色**（逻辑不变，色值随品牌换）：
- 底色：保持低饱和暖底（米黄/米白）最安全；严肃场合换浅灰蓝。
- 焦点色：**换成你自己的品牌主色**（钉钉蓝→企业 VI 色/北森橙），仍是唯一高饱和色、只给标题二条+CTA+产品化身。
- 压重色：暖业务用深棕，冷业务换藏青/墨绿，都替代纯黑。
- 徽章三色从辅助色环取三等分（蓝橙绿/红黄青），永不挨着放同色。

## 三、风格换肤对照（什么场合穿什么皮）

| 场合 | 换成什么 | 保留什么 |
|---|---|---|
| 内部轻推广、朋友圈、社群 | 本款贴纸拼贴（亲和、去冰冷感） | 全套 |
| 向上汇报、预算材料、CHO 汇报 | 扁平商务插画/轻拟物，去贴纸感 | 五段构图+文案方法+叙事弧 |
| 面向年轻员工、校招 | 像素风/表情包/国潮 | 全套叙事结构 |
| 正式品牌物 | 大字报留白风（底色+焦点色逻辑照旧） | 文案方法 |

## 四、Worked Example：套用到「报销机器人」

以祥承 AI 部门推数字员工为例（母题=发票，焦点色=企业 VI）：

- 栏目名：**报销不跑腿计划**
- 01 一沓发票，下课。一张照片，上班。（数字对比）
- 02 贴票这事，不必对齐到毫米。（熟语挪用）
- 03 一张发票，别再来回传。（痛点直给）
- 04 你说报销，它懂流程。（对仗拟人）
- 05 单据很多，你不用盯。（让步转折）
- 06 把贴票留在相机里，把下班还给自己。（取舍式收尾）
- 三徽章（每集换一组）：拍照自动识别 / 合规预校验 / 进度随时查
- 金句：**流程交给机器人，时间还给你。**
- 主视觉示例（04）：左边=皱纸+满桌发票+计算器+问号涂鸦，中间蓝色气泡机器人，右边=一张整齐的报销单卡片+绿勾。

## 五、通用版 AI 生成 Prompt 骨架

```
[底色]纸纹背景海报，[风格皮肤：手绘贴纸拼贴/扁平商务插画]风格。
顶部右侧[压重色]丝带标签写「产品名」，下方系列名+编号。
上部两条微倾斜的[母题物件]票笺叠放：前条浅底写痛点短句，
后条[焦点色]底白字写解法短句，带投影。
中部 Before→After 对比插画：左侧混乱（皱纸、乱飞标签、问号），
经[产品化身]漏斗，右侧变为整齐卡片+绿色对勾。
中下部三枚[母题变体徽章]横排，三种辅助色，各含小图标+≤7字卖点。
底部[压重色]通栏金句横幅，最下方[焦点色]药丸 CTA「[最低门槛动词]…」+放射短线。
四角点缀母题碎片、装饰符号。
```
