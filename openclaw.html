OpenClaw 个人 AI 中枢

自托管 · 飞书即控制台 · 全国产模型矩阵 · 一台 Mac 承载全部

缘起与主张

重度 AI 使用者的一天，入口是散的：笔记在一个 App、消息在飞书、代码在编辑器、日程在系统里。OpenClaw（MIT 开源、单操作者定位的个人 AI 助手框架，官方口号 "The AI that really does things"）提供了另一种可能——把这一切收进一台自己说了算的机器：Mac 当服务器，聊天软件当控制台，模型、记忆、技能、定时任务全部自己部署、自己审计。

主张：AI 中枢的第一性问题是边界，不是能力。部署这份实例时，花在「禁止它做什么」上的心思不比「让它做什么」少——本文最后一节就是这份边界清单。

部署架构

层做法
服务形态launchd 常驻服务（ai.openclaw.gateway）：开机自启、崩溃自动拉起，不需要任何人登录守护；版本 OpenClaw 2026.9.6
网关本地模式监听 18789，只绑定回环地址（loopback）+ token 认证——公网上摸不到这个端口；远程隧道（Tailscale）默认关闭
Web 控制台浏览器打开网关即得：会话管理、终端、cron 面板、配置审计，暗色主题开箱即用
聊天渠道飞书 WebSocket 长连接接入——出站连接即可工作，家用 Mac 不需要公网 IP、域名和证书；私聊白名单仅两个账号，群聊同样白名单制
语音MiniMax 语音合成（中文音色），日报类消息可直接听

模型矩阵：全国产 + 一个协议统一接入

四家供应商全部通过 Anthropic 兼容协议（个别走 OpenAI 兼容）接进同一张路由表，配置里只写 baseURL 和模型清单，切换供应商不动架构：

角色模型说明
主力GLM-5.3-Flash日常对话、工具调用的默认档，性价比优先
兜底DeepSeek Chat主力不可用时自动接管的 fallback 档
备选MiniMax M3 / M2.7M3 支持 100 万 token 上下文与视频输入，留给长材料任务
备选Kimi K2.6轻量快答档
周边能力搜索 / TTS / 向量网页搜索用 MiniMax，语音用 MiniMax，记忆向量化用智谱 embedding-3

另有一道 modelPolicy 白名单：只有清单内的模型允许被调用，Agent 自己「想换模型」是不行的。

记忆与人格：会做梦的助手

  • 五份人格档案：workspace 里放着 IDENTITY（身份）、SOUL（性格）、USER（对主人的认知）、MEMORY（工作记忆）、DREAMS（目标）五份 Markdown——它知道自己是谁、为谁工作。
  • 向量记忆库：embedding-3 驱动的语义检索，说过的话存得下、找得回。
  • 每日 03:00 记忆整理（Memory Dreaming）：夜里自动归档、去重、沉淀当日对话，第二天醒来记忆更干净。
  • 心跳每 2 小时（08:00–23:00 活跃时段）：只做自检与待办巡览，设为不主动发消息——安静是美德。

技能矩阵

官方内置的 60 多个 skill 裁剪到只开 3 个，另在 workspace 自建十余个——表面积越小越安全。代表性的几个：

技能做什么
得到大脑（Get 笔记）直连得到 App「Get 笔记」开放平台：往聊天里发链接、图片说「记一下」自动入笔记；可搜索、可管理知识库。skill 里写死了反幻觉边界——禁止编造笔记 ID、异步任务必须轮询到终态、没真正调 API 不许说「已保存」
飞书全家桶云文档 / 云盘 / 知识库 / 权限四个 skill，AI 能替我读写飞书文档
浏览器自动化 + Canvas可控的网页操作与画布渲染，海报、截图类任务的执行手
数据面金融数据（tushare）、宏观经济指标监控（FRED）、1Password 集成
内容与决策面新闻扫描、公众号文章、长文阅读、暗知识、数字分身、人生决策辅助等自建技能

新闻、局势、问候、训练四类任务都是「凌晨跑批、清晨送达」——AI 在我睡觉时干活，我醒来时结论已在聊天列表里。

安全与隐私：边界清单

这是整份部署里我最看重的部分。三层边界，全部写进配置，不靠模型自觉：

网络层——网关只绑回环地址 + token 认证，没有任何入站端口暴露在局域网之外；飞书走出站 WebSocket；远程访问隧道默认关闭。

会话层——私聊与群聊均为白名单制，名单之外的消息一律不理；笔记类技能内置隐私规则，群聊里不展示私人笔记内容。

设备层——八条敏感命令直接进 deny 列表，摄像头、录屏、通讯录、日历、提醒事项、短信，AI 从协议层就碰不到：

✕camera.snap（拍照）
✕camera.clip（录像）
✕screen.record（录屏）
✕contacts.add（写通讯录）
✕calendar.add（写日历）
✕reminders.add（写提醒）
✕sms.send（发短信）
✕sms.search（读短信）
