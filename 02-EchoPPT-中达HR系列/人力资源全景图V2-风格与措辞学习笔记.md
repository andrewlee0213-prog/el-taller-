### P6 招聘·流程：社招通用线 + 校招专线（配图：STAR 提问法）
- 胶囊"社招通用线" + 五步卡（圆号徽章 1–5 + ▸）：
  1. **需求确认**：依据业务策略确认人才策略 / 确认编制与JD
  2. **寻访候选**：内推 / 平台 / 猎头 / 校招
  3. **面试评估**：HR面+业务面，**2轮闭环**
  4. **Offer审批**：**5个工作日内**完成
  5. **入职融入**：背调后入职；员工层-伙伴计划、上级带教；管理层-专属融入计划
- 胶囊"27届校招专线" + **8个岗位 · 4城同步**；时间线：8月底 职位发布 → 9–10月 宣讲·笔试·面试 → 11月 发放Offer → 寒假 实习见习 → 2027.7 入职报到 → 入职后 第7期集训营
- 底部金句：**精准社招 · 精简校招 · 蓄力人才**
- 备注：*从需求到融入*

### P7 绩效·理念：绩效管理是为了更好地带团队
- 左侧大卡：公式 **绩效 = 目标对齐 + 过程改进 + 价值分配**（关键词 ED7D31）；三个"抓手"：对组织：战略落地的抓手 / 对管理者：带团队的抓手 / 对员工：成长与回报的依据
- 误区三连小卡（✗ 问 → 答）：
  - ✗ 绩效 = 年底打分？ → 绩效是全年持续的对齐与改进
  - ✗ 绩效 = HR 的事？ → 管理者才是第一责任人
  - ✗ 指标越多越好？ → 少而准，对齐战略才是关键
- 右侧理念四条（30pt 巨号 01–04）：
  1. **对齐业务** — 目标跟着经营节奏走，全员同向发力。
  2. **轻形式 · 重反馈** — 扁平管理、拒绝繁文缛节。重视员工辅导与反馈，件件有回音。
  3. **相对公平** — 没有绝对公平，只有相对公平。提倡**多劳多得、多创多得、多燃多得**。
  4. **发展导向** — 绩效是成长的镜子，不是秋后算账。以战代练，以评促长，达者为师。

### P8 绩效·流程：五步闭环（配图：四象限辅导）
- 五步卡：1 目标设定（定目标、通目标、谈目标 / 遵循SMART原则）→ 2 过程跟进（持续追踪与目标对焦 / 及时有效地反馈 / 抓准时机进行辅导）→ 3 评估校准（绩效考评〔打分与排序〕/ **271正态分布，Leader必须做出管理选择**）→ 4 反馈面谈（一人一谈，面向成长 / 2：管理期待，激发潜能 / 7：扬善砭过，明确要求 / 1：面向未来，正向引导）→ 5 结果应用（奖金 / 调薪 / 晋升 / 绩效改进 / 淘汰 + 紫字 **心要仁慈，刀要快**）
- 折线回环标注"进入下一绩效周期"；落地节奏胶囊：9月 绩效管理框架梳理 / 10月 绩效制度、流程、指标库 / 11-12月 试运行&复盘修订
- 底部金句：**为过程鼓掌，为结果买单。**
- 备注：*结果反哺下一轮目标设定，绩效不是终点而是起点。*

### P9 HRBP·业务身边的HR（既懂业务，又懂人）
- 渐变卡"为什么需要 HRBP"三条：多品牌 × 多平台 × 多城据点，业务复杂度已超出传统 HR 职能 / 直播「日销 + 大促」双节奏，HR 节奏必须贴着业务走 / 业务要的不是「后勤 HR」，是并肩作战、听得懂业务的伙伴

## 5. 措辞风格规律（复刻重点）

1. **标题公式：`模块·子题：一句口语化观点`**。不是"招聘管理"而是"招聘·标准：先画好像，再找对人"；不是"绩效管理理念"而是"绩效·理念：绩效管理是为了更好地带团队"。标题本身就传递立场。
2. **目录副题说人话**：每章配一句白话解释（"人力资源到底在做什么、创造什么价值"），把章节翻译成员工关心的问题。
3. **对仗三连/四连**是高频骨架：正道·利他·真实·情义｜定规则·内部专家｜管事务·共享服务｜贴业务·业务伙伴｜精准社招·精简校招·蓄力人才｜懂业务/推组织/选人才/促文化｜多劳多得、多创多得、多燃多得｜以战代练，以评促长，达者为师。
4. **公式化表达**：`绩效 = 目标对齐 + 过程改进 + 价值分配`；`HR | 组织能力的构建者`（竖线分隔定位句）。
5. **误区质疑句式**：`✗ 绩效 = 年底打分? → 答案`，先立靶再纠偏，适合理念宣贯页。
6. **数字钉子**：关键承诺全部数字化——2轮闭环、5个工作日内、8个岗位·4城同步、271正态分布、显性30%/隐性70%、3点期待、第7期集训营。
7. **金句收尾**（每页最多一句，20pt B 红字）：招对人远比招到人更重要（备注）/ 心要仁慈，刀要快 / 为过程鼓掌，为结果买单 / HR 的价值，在于赋能业务，让人与组织一起变强。
8. **口语与网感**："想打胜仗、能扛目标""用数据说话、不玩虚的""办事不费劲""别把问题攒到辞退时""HR是助攻""并肩作战"——管理词汇全部降维成大白话；"多燃多得"的"燃"是电商团队语感的点睛。
9. **中英混排**：中文为主、英文做小注或术语——选 SELECT / 用 DEPLOY / 育留 GROW、STAR提问法、1on1、Leader、Offer、JD、SMART、271。
10. **间隔号"·"当万能分隔符**：字与字（正 道）、词与词（定规则 · 内部专家）、并列项（内推 / 平台 / 猎头 / 校招 用斜杠）。
11. **直角引号「」**引用口语概念：「人才画像」「办事不费劲」「日销 + 大促」「后勤 HR」。
12. **备注页=讲稿金句**：备注不写流程只写提醒（"标准前置""从需求到融入""绩效不是终点而是起点"）。
13. **对管理层的诉求直接、不绕弯**："把 HR 当伙伴""用人部门是招聘第一责任人"——部门介绍 PPT 同时承担向上管理功能。
