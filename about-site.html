这间工坊是怎么盖的

你现在看到的这个网站，本身就是工坊里的一件作品。它没有用任何框架、没有构建步骤、没有数据库服务——一个单文件前端加一个 Node 脚本，就是全部。这篇说明把它拆开给你看。

架构：一件、一屋、一把钥匙

部分做法
前端单文件 index.html，原生 HTML/CSS/JS；作品和日志是两个数据文件（works.js / notes.js），加内容 = 改数据文件，主页自动渲染
服务端一个 server.js：静态服务 + 会话鉴权 + 知识库守卫 + 天气代理，Node 24 原生 node:sqlite，零外部依赖；工作台调度器按北京时间定点抓取油价 / B站 / Anthropic / arXiv / F1 / GitHub 趋势榜，PDF 上传自动转中英对照，文章可生成无登录只读的公开分享链接
账号体系scrypt 密码散列入库，HMAC 签名会话 cookie；guest / user / admin 三级可见性——作品可标 public / friends / private，未登录看不到该看的之外的一切
私有知识库La Biblioteca 整库鉴权下发（未登录访问直接 302 到登录页，数据文件 401），数据目录永不对 Web 暴露
天气服务端代理第三方 API，密钥只存在服务端，前端拿到的只有温度

视觉：玻璃拟态 × 东方漆色工坊

深漆底色上叠三团光斑与一层 SVG 噪点，卡片用半透明渐变玻璃（backdrop-blur）+ 内高光，主视觉是一枚琥珀色的锤子徽记。配色从「东方漆色研究」四页参考图逐像素取样，做成朱漆红 / 栗漆棕 / 犀皮彩 / 螺钿青四套大漆主题（共十套可换），默认朱漆红配鎏金强调；时钟模块按上海坐标实时算日出日落，日落后全站自动切玄黑、日出回朱漆红，点过圆点的访客以手动选择为准。文字排版中西语混搭——区块标题用西语（Proyectos / Cuaderno / Biblioteca），正文说人话。整站响应式，390 视口单列无横向溢出；阅读页自适应行宽（正文列保行长舒适，表格与内嵌 PDF 用满容器）。

玻璃拟态大漆主题 × 昼夜自动无框架零构建响应式

工程纪律：网站也是要验收的

  • 权限断言测试：202 项自动化断言常跑——路径穿越、未登录守卫、越权访问、可见性过滤、登出恢复、调度定点、分享链接边界；每次改动后必须全过。
  • 内容敏感词扫描：所有公开内容上线前过一遍词表 grep，客户名、内部系统名、密钥形态零容忍。
  • 视觉验收 = 用户接受度：每次改动逐页截图过一遍，桌面与手机视口都看。
  • 部署路线：境内合规部署——域名备案、nginx 反代、systemd 守护、HTTPS，上线前有一份自查清单逐项打勾；验证用临时管理员账号，用完即删。

踩过的坑（写下来，下次不踩）

  • 中文路径下 new URL().pathname 是百分号编码，直接喂给 fs / sqlite 会打不开文件——先过 fileURLToPath。
  • grid 布局里放宽表格 / 代码块，容器必须 min-width: 0，否则撑破整页。
  • 无头浏览器 fullPage 截图有平铺伪影——把视口拉到超过页高截视口，或用 CDP 的 captureBeyondViewport。
  • hidden 属性的隐藏会被作者样式里的 display:flex 压过——验「隐藏」必须看渲染结果，不能只看属性在不在。
  • 让语言模型直接写长格式文本，格式约定跟不稳——模型只出结构化 JSON、展示格式由服务端确定性渲染，一劳永逸。
  • 反代层不配 client_max_body_size 就是默认 1MB——上传端点上线时就要传一个大于默认值的文件实测整条链路。
