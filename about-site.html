这间工坊是怎么盖的

进度核对至 2026-11-11 · 已上线、待联调与本地试验分别标注

你现在看到的这个网站，本身就是工坊里的一件作品。它从一个单文件主页，逐步长成作品集、书房和私人工作台：页面用原生 HTML/CSS/JavaScript，核心服务用 Node 24 和内置 SQLite，不需要前端框架或打包构建。这篇说明把它拆开，也记录哪些已经可用、哪些还在试验。

最新进度：Studio 已公开，自动生成继续验证

2026-11-11 · PCB 固定教学样片已上线。作品入口已加入首页，介绍页与完整体验无需登录。公开版为 1.0.1，包含光粒子核心首页、PCB 四幕和 11 段字幕；独立 HTML 约 0.86 MiB，模型与显示代码内嵌，播放不依赖远程资源。

现在可以怎样体验

  1. 从核心进入案例：打开后先看到动态光粒子核心，点击「什么是 PCB？」进入教学；打开页面不会自动播放或发声。
  2. 看完四幕：依次认识裸板、材料层、铜线与过孔、元件装配。支持播放、暂停、拖动时间、倍速、切幕、旋转、聚焦与拆解。
  3. 用本地指令操作：输入「播放」「暂停」「拆解」「复原」「第二幕」或「返回核心」，控制当前案例。输入栏当前处理固定指令。
  4. 退出与继续：退出演示会停声并回到核心，继续演示保留进度；重新点击 PCB 案例则从头开始。作品页也可下载同一份独立 HTML。

旁白、导出与验证结果

  • 设备本地朗读：点击播放后才启用设备上可用的中文声线，没有合适声线时使用字幕。公开版不内嵌预生成录音，不调用远程语音服务。
  • 视频导出范围：设备朗读不录音；关闭朗读后，可在支持的浏览器中导出无声视频。公开版不提供原旁白 WAV 或有声视频下载。
  • 已完成检查：设备朗读 47 项工程检查通过；浏览器确认朗读启动、退出停声，播放时外部资源请求为 0。桌面 1280px 与手机 390px 检查无横向溢出，正式 HTTPS 资源与下载文件完整性检查通过。
  • 仍待体验验收：逐句人工听验、跨浏览器与跨设备操作，以及下载后真实双击本地文件打开尚未完成。声线与视频导出能力取决于访客设备和浏览器。

架构：一件、一屋、一把钥匙

部分做法
前端以 index.html 为入口的原生多页站点，复杂功能拆成独立脚本与样式；作品和日志由 works.js / notes.js 等数据驱动，加内容不必改主页布局
核心服务server.js 负责静态服务、会话鉴权、内容权限和 API，使用 Node 24 原生 node:sqlite；核心服务不依赖 npm 包，PDF 文本提取另用服务器上的 pypdf
账号体系scrypt 密码散列入库，HMAC 签名会话 cookie；guest / user / family / admin 四档访问级别，对应 public / friends / family / private 内容；账号与角色在管理台维护
书房与分享La Biblioteca 的目录、章节、搜索、划线与进度经鉴权按需下发，数据目录不对 Web 开放；管理员可为整书或单章建立有范围和期限限制、可吊销的免登录只读分享链接
私人工作台仅管理员可用：定点抓取资讯、记录工作、按项目总结与排程，日历整合备忘和月度解读；Agenda 单向同步代码已部署，真实账号授权与日程联调仍待完成
天气与外部服务服务端代理天气、文章翻译与 AI 问读，密钥保存在服务端；浏览器只收到业务结果，不接触服务凭据

视觉：玻璃拟态 × 东方漆色工坊

深漆底色上叠三团光斑与一层 SVG 噪点，卡片用半透明渐变玻璃（backdrop-blur）+ 内高光，主视觉是一枚琥珀色的锤子徽记。配色从「东方漆色研究」四页参考图逐像素取样，做成朱漆红 / 栗漆棕 / 犀皮彩 / 螺钿青四套大漆主题（共十套可换），默认朱漆红配鎏金强调；时钟模块按上海坐标实时算日出日落，日落后全站自动切玄黑、日出回朱漆红，点过圆点的访客以手动选择为准。文字排版中西语混搭——区块标题用西语（Proyectos / Cuaderno / Biblioteca），正文说人话。整站响应式，390 视口单列无横向溢出；阅读页自适应行宽（正文列保行长舒适，表格与内嵌 PDF 用满容器）。

工程纪律：网站也是要验收的

  • 自动化回归：按改动范围检查登录与权限、书库与分享、工作台调度；历法引擎另做对照测试，实验功能分别核对来源、权限和版本。代码回归通过、真实模型结果与视觉效果分别验收。
  • 内容敏感词扫描：所有公开内容上线前过一遍词表 grep，客户名、内部系统名、密钥形态零容忍。
  • 视觉验收 = 用户接受度：每次改动逐页截图过一遍，桌面与手机视口都看。
  • 部署路线：域名备案、nginx 反代、systemd 守护与 HTTPS；工作区有其他实验时，只按白名单发布本次文件，先核对线上基线、备份和回滚，再验资源与权限，避免把未完功能一并上线。

踩过的坑（写下来，下次不踩）

  • 中文路径下 new URL().pathname 是百分号编码，直接喂给 fs / sqlite 会打不开文件——先过 fileURLToPath。
  • grid 布局里放宽表格 / 代码块，容器必须 min-width: 0，否则撑破整页。
  • 无头浏览器 fullPage 截图有平铺伪影——把视口拉到超过页高截视口，或用 CDP 的 captureBeyondViewport。
  • hidden 属性的隐藏会被作者样式里的 display:flex 压过——验「隐藏」必须看渲染结果，不能只看属性在不在。
  • 让语言模型直接写长格式文本，格式约定跟不稳——模型只出结构化 JSON、展示格式由服务端确定性渲染，一劳永逸。
  • 反代层不配 client_max_body_size 就是默认 1MB——上传端点上线时就要传一个大于默认值的文件实测整条链路。
